# Qué convenciones de nombramiento usaremos?

| Elemento | Convención | Ejemplo |
| --- | --- | --- |
| Clases | PascalCase, sustantivos | `UserService`, `OrderRepository` |
| Métodos | camelCase, empiezan con verbo | `getUserById()`, `calculateTotal()` |
| Variables | camelCase, descriptivas | `userName`, `isActive`, `totalPrice` |
| Constants | UPPER_SNAKE_CASE | `MAX_RETRY_COUNT`, `API_BASE_URL` |
| Archivos | kebab-case o igual que la clase | `user-service.ts`, `UserService.java` |
| Carpetas | kebab-case o minúsculas | `user-management/`, `utils/` |
